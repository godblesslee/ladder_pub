# 信息架构与用户流

## 1. 信息架构

## 1.1 用户端

- 首页
- 活动详情
- 酒款测评
- 我的活动
- 我的酒款
- 我的测评记录
- 个人设置

## 1.2 组织者后台

- 仪表盘
- 活动管理
- 酒款数据库
- 测评模板管理
- 测评记录查看
- 用户与权限

## 2. 首页结构

首页建议按以下顺序组织：

### 2.1 已上线活动

展示：

- 即将开始
- 正在进行
- 已公开可回顾

### 2.2 我参与的活动

展示字段：

- 活动名称
- 时间
- 状态
- 我的完成进度

排序：

- 按活动时间先后排序

### 2.3 我测评过的酒款

展示字段：

- 酒款名称
- 厂牌
- 我的最高/最近评分
- 最近参与的活动

排序：

- 按总评分从高到低

## 3. 用户核心流程

## 3.1 用户进入活动并完成测评

1. 用户打开首页
2. 进入某场活动
3. 查看本场酒款列表
4. 点击一款酒进入测评页
5. 填写模板选项
6. 填写总评分
7. 填写公开评论/感受
8. 提交并返回酒款列表
9. 查看本场完成进度

## 3.2 用户回看自己的品鉴记录

1. 打开“我测评过的酒款”
2. 按评分排序浏览
3. 点击某款酒
4. 查看自己在不同活动中的测评记录
5. 对比同一酒款的不同场次体验

## 3.3 用户查看活动回顾

1. 打开活动详情
2. 查看酒款列表与已公开评论
3. 浏览其他用户对单款酒的公开感受

## 4. 组织者核心流程

## 4.1 创建活动

1. 进入后台活动管理
2. 新建活动基础信息
3. 选择测评模板
4. 添加活动酒款
5. 发布活动

## 4.2 维护酒款数据库

1. 进入酒款数据库
2. 新增/编辑厂牌、名称、风格、容量、国别、ABV、图片
3. 维护标准化字段，减少重复数据

## 4.3 维护测评模板

1. 进入模板管理
2. 创建模板
3. 增加分组与字段
4. 配置字段类型、选项、排序、必填规则
5. 发布模板供活动使用

## 5. 关键页面建议

## 5.1 活动酒款列表页

每个酒款卡片建议显示：

- 出场顺序
- 酒款图
- 厂牌 + 名称
- 风格
- 我的提交状态
- 进入测评按钮

## 5.2 酒款测评页

页面结构建议：

- 酒款基础信息
- 模板分组内容
- 总评分
- 公开评论
- 私密备注
- 保存/提交按钮

交互建议：

- 支持暂存草稿
- 支持提交后再编辑，直至活动锁定

## 5.3 我的酒款页

建议提供：

- 搜索
- 排序
- 筛选（风格、国别、评分）
- 列表视图与记录视图切换

## 6. 权限与可见性

- 用户自己的完整测评记录：仅本人可见
- 公开评论字段：其他用户可见
- 组织者：可查看活动内记录统计与公开内容
- 管理员：可管理模板和基础库
